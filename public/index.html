Get your data out of Salesforce / HubSpot (2 min)
Salesforce: Reports tab → New Report → Accounts → add columns Account Name, Annual Revenue, Customer Success Date, Last Activity → Run → Export → CSV only → save as accounts.csv.
Tickets: report on Cases (Case Number, Account ID, Status, Created Date) → tickets.csv.
HubSpot: Reports → Reports → create a Contacts/Companies report → Export → CSV. Map company name → id, MRR → mrr, renewal/next-bill date → renewal_on, last activity → last_contact_on.
Column names that don't match are fine — the banner will tell you exactly what couldn't be used.
